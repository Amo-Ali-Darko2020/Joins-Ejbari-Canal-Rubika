# سازنده عمو علی 
⚡ جوین اجباری کانال روبیکا

A powerful Rubika Force Join Bot

یک پروژه برای مدیریت عضویت اجباری کاربران در کانال روبیکا، با راه‌اندازی ساده از طریق Termux.

---

🛠️ پیش‌نیازها

- گوشی اندرویدی
- برنامه "Termux" (https://github.com/termux/termux-app)
- اتصال اینترنت
- فایل‌های پروژه و تنظیمات لازم ربات

🚀 راه‌اندازی قدم‌به‌قدم

01 — نصب پیش‌نیازها

Termux را باز کنید و دستور زیر را اجرا کنید:

pkg update && pkg upgrade -y
pkg install python git -y

02 — دریافت پروژه

git clone https://github.com/Amo-Ali-Darko2020/Joins-Ejbari-Canal-Rubika.git
cd Joins-Ejbari-Canal-Rubika

03 — نصب کتابخانه‌ها

bash install.sh

04 — تنظیم ربات

قبل از اجرا، تنظیمات موردنیاز را در فایل "bot.py" بررسی کنید و مقادیر لازم را مطابق راهنمای پروژه وارد کنید.

05 — اجرای ربات

bash run.sh

---

🧩 ساختار پروژه

- "bot.py" — فایل اصلی ربات
- "install.sh" — نصب پیش‌نیازها
- "requirements.txt" — فهرست کتابخانه‌ها
- "run.sh" — اجرای ربات

🔒 نکات مهم

- اطلاعات ورود و کلیدهای خصوصی خود را منتشر نکنید.
- برای عملکرد صحیح، تنظیمات ربات باید کامل باشند.
- در صورت بروز خطا، ابتدا نصب کتابخانه‌ها و تنظیمات را بررسی کنید.
